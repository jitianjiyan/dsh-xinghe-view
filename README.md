# 星河视图 · Galaxy View

把 DSH 的工作区变成星海：**每个工作区是一个恒星系，每个会话是一颗绕行行星**。

左侧栏底部点击星系图标进入，整个内容区变成一片可以缩放、拖拽的深空。

## 功能

- **恒星系布局** —— 每个工作区一颗恒星，恒星上写工作区名；会话按最近活跃度分配到轨道，越近越靠内、行星越大越亮。
- **搜索** —— 顶部搜索栏同时匹配会话名、工作区名、**全拼**和**首字母**（如 `xhst` → 星河视图）。`Ctrl/Cmd + K` 聚焦，`↑↓` 选择，`Enter` 打开。
- **单击看信息，双击进入** —— 单击行星弹出会话卡（标题、路径、相对时间、运行状态、消息条数、token 用量、最近摘要）；双击行星或卡片上的按钮进入会话。单击恒星看该工作区全部会话；双击恒星把镜头推近该星系，双击空白回到全景。
- **滚轮缩放** —— 围绕球心缩放，`0.06×` 到 `6×`，远景自动隐藏行星标签避免糊成一团。
- **会话连线** —— 三种方式：右键行星 →「链接到会话…」再点目标；右键 →「从列表选择链接目标…」；或直接拖动一颗行星到另一颗。连线是细光线，右键可删除，存 `localStorage` 并同步到宿主。
- **链接会话互通** —— 连起来的会话可以读到彼此的内容，顶栏两档切换：
  - **会话互通**：注册只读工具 `xinghe_read`，模型可以按需翻阅已链接会话的最近消息。零副作用——插件不写任何会话日志。
  - **仅连线**：只画线，`xinghe_read` 会拒绝读取。

## 安装

```bash
dsh plugin add dsh-xinghe-view
```

或在 DSH 里用 `plugin_manager`：

```
plugin_manager  action=install_bundle  target=dsh-xinghe-view
```

本地开发时 `target` 直接给包目录的绝对路径即可（会以 link 方式接入）。

## 数据

- 连线与模式：浏览器 `localStorage`（`xinghe-view.links.v1` / `xinghe-view.mode.v1`）。
- 宿主侧副本：`~/.dsh/xinghe-view/links.json`，通过 `GET/POST /xinghe/links` 同步。

## 兼容

| 运行形态 | 状态 |
| --- | --- |
| DSH Web（浏览器打开 `127.0.0.1:3080`） | 完整可用，顶栏不需要为标题栏让位 |
| DSH 桌面版（Tauri） | 完整可用，自动为窗口标题栏让出高度 |
| DSH 桌面版（Electron） | 完整可用，默认走系统原生边框，不额外留白 |

页面只在 `main` 与 `sidebar.panellist` 两个插槽里渲染，不碰 app root，不改他人 DOM，颜色除深空美术部分外都取自 `--dsw-alias-*`。

## 限制

- 只有**已加载**（live）的会话能被读取消息；未加载的会话显示为「未加载，读不到消息」。
- 互通依赖各会话自己的上下文组装，不会主动唤醒一个空闲会话。
- 宿主路由 `/xinghe/links` 只监听本机 DSH 服务，没有额外鉴权——不要把 DSH 服务暴露到公网。
